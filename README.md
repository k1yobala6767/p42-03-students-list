## Условие

В проекте уже есть готовый класс Student (файл Student.cs, тот же, что в лекции «Классы и объекты»): имя Name, группа Group, метод AddScore, свойства Count, Average, HasScores и ToString. Класс менять нельзя: задача в том, чтобы правильно им пользоваться.

Напишите в Program.cs три метода:
1) AddScores(s, scores) добавляет студенту все оценки из массива через s.AddScore(...). Неверные оценки (меньше 0, больше 100, больше 10 штук) класс сам не примет, свою проверку писать не нужно.
2) FormatLine(number, s) возвращает строку списка «номер. имя: средний балл», средний округлён до десятых: Math.Round(s.Average, 1). Если у студента нет оценок (s.HasScores), вместо балла пишется «нет оценок».
3) PrintList(group) выводит всю группу: по одной строке FormatLine на студента, нумерация с 1.

Это первое задание серии: в Заданиях 8 и 9 будем искать студентов с высоким баллом и сортировать их по имени.

**Примеры**

```
Студент: Сериков Дамир, оценки 72, 65, 80
FormatLine(1, s) → 1. Сериков Дамир: 72,3

Студент: Тестов Тест, оценки 50, 150, 70, -10, 90
После AddScores: Count = 3, Average = 70
Пояснение: 150 и -10 класс Student не принял (AddScore вернул false)

Студент: Ли Виктор, оценок нет
FormatLine(6, s) → 6. Ли Виктор: нет оценок

PrintList(group), начало вывода:
1. Сериков Дамир: 72,3
2. Ахметова Айгерим: 91,7
3. Ким Анна: 95
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-03-students-list
   cd p42-03-students-list
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри методов `AddScores`, `FormatLine` и `PrintList` (вместо строк `// TODO`). Не меняйте `Student.cs` и методы `Main`, `Check`.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
